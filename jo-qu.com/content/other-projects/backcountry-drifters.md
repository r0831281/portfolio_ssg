# Backcountry Drifters

A modern booking and content management platform for Backcountry Drifters' guided fly-fishing adventures in Alberta. The platform gives guests an accessible way to discover trips and request bookings, while guides can manage trips, testimonials, availability, and bookings through an admin dashboard.

## Project Overview

**Type:** Client project  
**Role:** Full-stack developer  
**Client:** Backcountry Drifters Fly Fishing

## Key Features

- Trip discovery with detailed descriptions, difficulty ratings, pricing, duration, and location
- Filtering and search for finding the right adventure
- Booking requests with tracking and confirmation notifications
- Admin dashboard for trips, testimonials, and bookings
- Role-based authentication and real-time Firestore synchronization
- Responsive, accessible design optimized for desktop and mobile

## Stack

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, React Router
- **Backend:** Firebase Authentication, Cloud Firestore, Firebase Analytics
- **Security:** DOMPurify sanitization, input validation, Firestore Security Rules, rate limiting
- **Deployment:** Firebase Hosting

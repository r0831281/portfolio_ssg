# Backcountry Drifters

Een modern boekings- en contentmanagementplatform voor de begeleide vliegvisavonturen van Backcountry Drifters in Alberta. Gasten kunnen eenvoudig trips ontdekken en boekingen aanvragen, terwijl gidsen trips, testimonials, beschikbaarheid en boekingen beheren via een admin dashboard.

## Project Overzicht

**Type:** Klantproject  
**Rol:** Full-stack ontwikkelaar  
**Klant:** Backcountry Drifters Fly Fishing

## Belangrijkste Functies

- Trip ontdekking met beschrijvingen, moeilijkheidsgraad, prijs, duur en locatie
- Filters en zoekfunctie om het juiste avontuur te vinden
- Boekingsaanvragen met tracking en bevestigingsmeldingen
- Admin dashboard voor trips, testimonials en boekingen
- Rolgebaseerde authenticatie en real-time synchronisatie met Firestore
- Responsief en toegankelijk ontwerp voor desktop en mobiel

## Stack

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, React Router
- **Backend:** Firebase Authentication, Cloud Firestore, Firebase Analytics
- **Security:** DOMPurify-sanitization, inputvalidatie, Firestore Security Rules en rate limiting
- **Deployment:** Firebase Hosting

# Laura en Wout

A QR-based wedding RSVP application built to give day and evening guests a simple, tailored invitation and response flow. Guests scan the appropriate QR code, complete the matching RSVP form, and responses are validated and stored securely in Firestore.

## Project Overview

**Type:** Personal project  
**Role:** Full-stack developer

## Key Features

- Separate RSVP flows for day guests and evening guests
- QR-code-based invitation links
- Validation for attendance, plus-ones, dietary restrictions, and partial-day attendance
- Protected admin page with RSVP overview and CSV export
- Static frontend deployed with Cloudflare Pages
- Worker API with Firestore storage and server-side validation

## Stack

- **Frontend:** HTML, CSS, and JavaScript
- **Backend:** Cloudflare Workers and Firebase Firestore
- **Deployment:** Cloudflare Pages
